\## Three Git Commands I Learned



1\. `git status` — Checks the status of files in a Git repository.

2\. `git add` — Stages changes before committing them.

3\. `git commit -m "message"` — Saves staged changes in the local Git history.



\## Purpose of GitHub



GitHub is a platform for hosting Git repositories, sharing code, and collaborating with other developers.



\## One Benefit of Using Branches



Branches allow developers to work on changes separately without directly affecting the main branch.
